🎯 What You'll Learn

By the end of this guide, you'll know how to:
  • Install Git on your computer
  • Create your first repository
  • Save changes to your code
  • Upload your project to GitHub

📋 What You Need

  • 💻 A computer with internet access
  • 🌐 A GitHub account (Sign up here)
  • ⏰ 30 minutes of your time

🤔 What is Git and GitHub?

Git

A tool that helps you track changes in your code. Think of it like a "Save" button with superpowers - it remembers every version of your files.

GitHub

A website where you can store your code online and share it with others.

💾 Step 1: Install Git

Windows

1
Go to git-scm.com/downloads
Click "Download for Windows"
Run the installer and click "Next" through all the steps
Open Command Prompt and type: git --version
You should see something like: git version 2.x.x

Mac

1
Open Terminal
Type: git --version
If Git isn't installed, it will ask you to install it - click "Install"
Wait for it to finish, then try git --version again

Linux (Ubuntu/Debian)

sudo apt update
sudo apt install git
git --version

⚙️ Step 2: Set Up Git

Tell Git who you are (do this once):

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
Replace "Your Name" and the email with your actual information.

📁 Step 3: Create Your First Project

1
Create a folder for your project
mkdir my-first-project
cd my-first-project
2
Turn it into a Git repository
git init
3
Create a simple file
echo "# My First Project" > README.md
4
Check what Git sees
git status

💾 Step 4: Save Your Work

Think of this as creating a snapshot of your project:
1
Add your file to the staging area
git add README.md
2
Commit (save) your changes
git commit -m "Add README file"
The message in quotes describes what you did.

🌐 Step 5: Create a GitHub Repository

  1. Go to github.com and log in
  2. Click the "+" button in the top right, then "New repository"
  3. Name it my-first-project
  4. Leave everything else as default
  5. Click "Create repository"

☁️ Step 6: Upload Your Code to GitHub

1
Connect your local project to GitHub
git remote add origin https://github.com/YOUR-USERNAME/my-first-project.git
Replace YOUR-USERNAME with your actual GitHub username.
2
Upload your code
git push -u origin main

You might need to enter your GitHub username and password.

3
Check your GitHub page
Go to https://github.com/YOUR-USERNAME/my-first-project - your code is now online!

🔄 Daily Workflow

When you make changes to your project:
# See what changed
git status

# Add your changes
git add .

# Save your changes with a message
git commit -m "Describe what you changed"

# Upload to GitHub
git push

📝 Common Commands

Command What it does
git status Shows what files have changed
git add . Stages all changed files
git commit -m "message" Saves changes with a description
git push Uploads changes to GitHub
git pull Downloads latest changes from GitHub
git log Shows history of changes

💡 Tips for Beginners

Commit Often

Save your work frequently with descriptive messages

Clear Messages

"Fix login bug" is better than "fix stuff"

Check Status

Use git status regularly - it tells you what's happening

Don't Panic

You can usually undo mistakes in Git

Practice

Create small test projects to get comfortable

🛠️ Troubleshooting

❌ "Permission denied" when pushing to GitHub?

  • Make sure you're using the correct username
  • You might need to use a personal access token instead of your password

❌ "Nothing to commit" message?

  • You haven't made any changes, or you forgot to git add your files

❌ Forgot to add a file?

  • Use git add filename then git commit --amend to add it to your last commit

🚀 What's Next?

  • Explore GitHub's features like Issues and Pull Requests
  • Try collaborating with others on projects
  • Look into more advanced Git commands
